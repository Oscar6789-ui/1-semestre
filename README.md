# Asistente de Telegram a Google Calendar

Este es un proyecto personal para automatizar la lectura de grupos de Telegram.

## Objetivo
- Leer los mensajes de grupos específicos sin que los demás usuarios vean un bot.
- Generar un resumen diario de lo más importante.
- Detectar tareas pendientes con fechas límite.
- Enviar automáticamente esas tareas a Google Calendar.

## Tecnologías (Planeadas)
- Python
- Telethon (API de usuario de Telegram)
- Inteligencia Artificial (para resúmenes)
- Google Calendar API
